## 1. Logique commerciale adaptée au site

Rappel Alertes informe sur les **rappels produits officiels** (RappelConso). La monétisation doit rester secondaire à l’utilité :

| Besoin lecteur | Angle commercial plausible | Priorité |
|---|---|---|
| Remplacer un produit rappelé | Lien affilié vers un produit de remplacement (ex. Amazon.fr) | Haute |
| Acheter chez une enseigne FR | Programmes retail via réseaux (Awin, TradeTracker, Affilae) | Moyenne |
| Après un appareil / dommage | Comparateur assurance habitation (lead) | Moyenne, plus tard |
| Fiches sponsorisées | Partenariats ponctuels avec marques / enseignes | Basse (après trafic) |

**À éviter :** vendre la peur, recommander un produit dangereux, affirmer un revenu futur, mélanger rappel officiel et pub sans mention claire.

## 4. Marquage des contenus commerciaux (obligation FR)

### Règles (sources)

- DGCCRF / economie.gouv.fr — devoirs des contenus avec contrepartie : https://www.economie.gouv.fr/influenceurs-quels-sont-mes-devoirs  
- ARPP — identification des communications commerciales : https://www.arpp.org/nous-consulter/regles/regles-de-deontologie/identification-de-la-publicite-et-des-communications-commerciales-et-de-annonceur/  
- ARPP — communication publicitaire numérique : https://www.arpp.org/nous-consulter/regles/regles-de-deontologie/recommandation-communication-publicitaire-numerique/

**Principe :** dès qu’il y a contrepartie (commission affiliation, partenariat, produit offert…), le caractère commercial doit être **clair, lisible, identifiable**, et l’annonceur identifiable. Sinon risque de pratique commerciale trompeuse.

### Mentions prévues sur Rappel Alertes

1. **Pied de page global** (dès le premier lien affilié actif) :

   > Certaines pages peuvent contenir des liens d’affiliation : si vous achetez via ces liens, Rappel Alertes peut percevoir une commission, sans surcoût pour vous. Cela n’influence pas les informations reprises de RappelConso.

2. **Sur chaque bloc commercial** (près du lien) :

   > Lien commercial / affiliation — [Nom du marchand]

   ou : `Contenu commercial` / `Partenariat` selon le cas.

3. **Page dédiée** `a-propos.html` ou `mentions-legales` : expliquer affiliation, indépendance éditoriale sur les rappels officiels, et que les données RappelConso ne sont pas sponsorisées.

4. **Ne jamais** présenter un lien affilié comme « information officielle » ou comme faisant partie de la fiche RappelConso.

## 5. Plan technique (après approbation des comptes)

À activer **seulement** quand au moins un compte est approuvé et que Carole a validé l’insertion.

### 5.1 Données

Dans `data/rappels.json` (ou fichier annexe `data/affiliates.json`) :

```json
{
  "id": "23913",
  "affiliate": {
    "enabled": true,
    "network": "amazon",
    "label": "Voir un produit de remplacement (lien commercial)",
    "url": "https://www.amazon.fr/dp/…?tag=IDENTIFIANT",
    "merchant": "Amazon.fr",
    "disclosure": "affiliation"
  }
}
```

Règles :
- `enabled` false par défaut ;
- pas de lien si le produit est dangereux à « remplacer » à la légère (ex. médicament) ;
- URL toujours HTTPS ; tag / tracking du réseau.

### 5.2 Affichage

- Template fiche : bloc distinct sous « Conduite à tenir », style différent du lien officiel RappelConso.
- Classe CSS `.commercial` + texte de disclosure inline.
- Tracking clics : paramètres UTM (`utm_source=rappel-alertes&utm_medium=affiliate&utm_campaign=…`) + reporting du réseau.

### 5.3 Automatisation future (Mogul)

1. Détecter fiche publiée sans lien affilié pertinent.  
2. Proposer (brouillon) un lien via l’outil du réseau (jamais inventé).  
3. Contrôles qualité : disclosure présente, pas de doublon, catégorie autorisée.  
4. Publier auto **uniquement** si règles validées par Carole au préalable ; sinon brouillon + alerte.
